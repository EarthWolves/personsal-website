# rraval.com

Personal site. Plain HTML/CSS/JS, so there's no build step. Preview locally with `python3 -m http.server`.

- Change links (email, LinkedIn, Calendly, CRM endpoint) in `assets/site.js` → `SITE`.
- Press ⌘K / Ctrl+K anywhere for the command menu.
- New post: copy `writing/why-i-started.html`, then add a row in `index.html#writing`.
- Photos: drop files in `photos/`, then replace the `.ph` placeholders in `gallery.html`.
